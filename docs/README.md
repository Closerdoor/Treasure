## 3. 文档使用规则

- 当前前台站点不是博客或笔记站点。
- 前台页面不直接展示 `md` 文档内容。
- `data.json` 是前台详情页与列表聚合的正式结构化数据来源。
- 与 `data.json` 一一对应的 `md` 文件仅用于人工审阅、对照和后续归档。
- 若草案文档与有效文档冲突，以“当前有效文档”为准。

## 4. 当前 V1 共识摘要

- 站点结构固定为：`首页 -> 模块列表页 -> 详情页`
- 模块列表页共有四个：影视、书、游戏、音乐
- 四个模块列表页不要求完全通用，可以分别设计
- 当前先优先推进影视模块
- V1 正式支持深色 / 浅色主题切换
- 影视列表页默认展示影视模块下全部内容；若从首页进入并携带筛选条件，则自动激活对应筛选项
- 影视列表页 V1 支持：搜索、子模块、类型、地区、年份、标签筛选
- 列表页 V1 暂不开放用户排序切换，默认按上映时间排序
- 电影详情页上方展示基础信息，下方通过 Tab 分区展示扩展信息
- 电影详情页右栏放置系列作品与相似作品；系列作品不存在时可隐藏该模块
- V1 评分展示以豆瓣 / IMDb / TMDB / 烂番茄四方评分的综合平均值为主
- V1 前台不额外展示馆长评分或馆长评论字段
- Giscus 评论区保留在详情页中显示
