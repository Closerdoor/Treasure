# 个人收藏馆设计文档 01：信息架构与页面规则

## 1. 项目定位

本项目是一个精选型个人收藏馆，不是全量资料库，也不是博客或笔记站点。

核心特征：

- 只收录经过馆长筛选的作品
- 前台以结构化资料展示为主，而不是以 Markdown 长文为主
- 当前前台以外部平台资料聚合展示为主，不额外强调馆长主观表达
- 展示站点采用静态站点方案并部署到 GitHub Pages
- 内容整理、补全、确认、归档在本地完成

## 2. 总体结构

项目分为两层：

1. 展示站点
   - 面向访客
   - 当前计划使用 Astro 静态生成
   - 部署到 GitHub Pages
   - 前台页面消费结构化数据，不直接展示审阅用 Markdown

2. 本地内容工坊
   - 面向馆长
   - 负责录入、搜索、补全、确认、整理、审阅与归档
   - 保存采集缓存、来源记录、工作数据与审阅材料

## 3. 页面层级

当前站点的页面结构固定为三层：

```text
首页 -> 模块列表页 -> 详情页
```

说明：

- 首页是总入口，同时承担适度的内容发现职责
- 模块列表页展示某一模块下的全部内容，并承担搜索、筛选、分页职责
- 详情页展示单条作品的完整结构化资料

## 4. 模块范围

当前模块共四个：

- 影视
- 书
- 游戏
- 音乐

设计原则：

- 四个模块列表页不要求完全共用一套界面
- 各模块可以根据内容特征分别设计
- 全站只统一导航、基础交互、视觉气质与主题机制
- V1 当前先优先推进影视模块

## 5. 首页定位

首页不是纯导航页，也不是纯内容门户页，而是两者之间的混合型入口页。

首页承担的职责：

- 建立站点的视觉气质与第一印象
- 作为四大模块的总入口
- 提供适度的内容预览与分发能力
- 帮助用户快速进入某个模块或某一类内容

当前首页结构方向：

1. 炫酷的首屏内容区
   - 兼顾视觉冲击力与站点说明
   - 可包含标题、说明、精选内容或视觉背景

2. 按模块依次展示内容预览区
   - 影视
   - 书
   - 游戏
   - 音乐

3. 每个模块预览区包含：
   - 模块标题
   - 子模块 Tab 或分类入口
   - `查看更多` 入口
   - 1 到 2 行作品卡片预览

4. 交互规则
   - 点击作品卡片进入对应详情页
   - 点击 `查看更多` 进入该模块列表页
   - 若从首页子模块入口进入模块列表页，可自动携带筛选条件

## 6. 模块列表页定位

模块列表页负责展示该模块下全部内容，并提供统一的内容检索入口。

共同职责：

- 展示该模块下全部内容
- 搜索
- 筛选
- 分页
- 跳转详情页

说明：

- 不要求四个模块列表页完全通用
- 当前先定义影视模块列表页，其它模块后续再细化

## 7. 影视模块列表页规则

影视模块包含：

- 电影
- 电视剧
- 动漫
- 纪录片
- 短片

当前规则：

- 默认展示影视模块下全部内容的混合列表
- 若从首页进入并带有筛选条件，则自动激活对应筛选项
- V1 支持的筛选项包括：
  - 搜索
  - 子模块
  - 类型
  - 地区
  - 年份
  - 标签
- V1 暂不开放用户自定义排序切换
- 默认按上映时间排序

## 8. 详情页定位

详情页直接展示对应 `data.json` 中的结构化数据。

页面原则：

- 上方展示基础信息
- 下方通过 Tab 分区展示不同类别的扩展资料
- 右侧放置关联内容，而不是广告位

当前电影详情页结构方向：

- 左侧主内容：
  - 基础信息
  - 详情介绍
  - 演职员
  - 精彩影评
  - 视频
  - 图片（剧照 / 海报）
  - 音乐
  - 外部来源
- 右侧补充信息：
  - 系列作品
  - 相似作品

说明：

- 如果没有系列作品，则隐藏该模块
- 系列作品和相似作品均支持点击跳转到对应详情页
- Giscus 评论区保留在详情页中显示
- `详情介绍` 区使用作品级 `story` 字段
- `synopsis` 仅承担短简介职责

## 9. 正式数据与审阅材料边界

当前已确认的边界如下：

- 前台不直接展示 `md` 文档
- `data.json` 是当前前台正式结构化数据来源
- 与 `data.json` 一一对应的 `md` 文件只用于人工审阅、对照与后续归档
- 站点不是博客，因此不以 Markdown 正文作为页面主体来源

## 10. 评分展示规则

V1 的电影主评分不是馆长评分，而是四个外部平台评分的综合平均值。

当前评分来源：

- 豆瓣
- IMDb
- TMDB
- 烂番茄

展示规则：

- 页面至少展示综合平均值
- 在需要的场景下，可补充展示四个来源的原始评分
- V1 当前不额外展示馆长评分字段

## 11. 主题与视觉策略

V1 正式支持深色 / 浅色主题切换。

说明：

- 深色主题强调资料馆气质与海报表现力
- 浅色主题强调目录感与资料阅读体验
- 两套主题都应作为正式体验成立，而不是简单反色

## 12. 当前 V1 约束总结

后续所有设计与实现应遵守以下约束：

- 前台不是博客/笔记站点
- 前台不直接展示 `md` 文件
- `data.json` 是前台正式数据来源
- 站点结构固定为：首页 -> 模块列表页 -> 详情页
- 四个模块列表页可以分别设计，不要求完全通用
- 当前优先推进影视模块
- 影视列表页默认展示全部内容，支持首页携带筛选跳转
- 列表页 V1 支持搜索、子模块、类型、地区、年份、标签筛选
- 列表页默认按上映时间排序
- V1 正式支持深色 / 浅色主题切换
- 详情页保留 Giscus 评论区
- V1 当前不额外展示馆长评分或馆长评论字段
