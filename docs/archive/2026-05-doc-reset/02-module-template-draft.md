# 个人收藏馆设计文档 02：模块模板与页面边界

## 1. 模板设计原则

本项目不采用“全站一套页面模板完全复用”的方式，而采用以下原则：

1. 全站统一基础骨架
   - 导航
   - 主题切换
   - 基础视觉系统
   - 搜索入口的可达性
   - 页面节奏与基础交互习惯

2. 模块级页面独立设计
   - 影视模块列表页
   - 书模块列表页
   - 游戏模块列表页
   - 音乐模块列表页

3. 详情页按模块内容特征延展
   - 各模块详情页共享“基础信息 + 分区内容 + 关联推荐”的思路
   - 但不同模块可采用不同的字段组织和信息区块

目标是同时满足：

- 模块差异足够大
- 全站仍然保持统一的产品气质
- 后续新增内容能稳定接入现有结构

## 2. 全站统一骨架

所有页面共享以下基础结构：

1. 顶部导航
   - 站点名
   - 四大模块入口
   - 搜索入口
   - 关于页入口
   - 主题切换

2. 主内容区
   - 首页为首屏 + 模块预览区
   - 列表页为筛选区 + 内容列表 + 分页
   - 详情页为基础信息区 + 分区内容区 + 侧栏关联区

3. 页脚
   - 版权说明
   - 数据来源说明
   - 评论系统说明

## 3. 首页模板方向

首页定位不是“纯导航页”，也不是“强策展长文页”，而是总入口与内容发现之间的混合型首页。

当前首页结构方向：

1. 首屏内容区
   - 有视觉冲击力
   - 明确站点气质与定位
   - 可包含标题、说明、精选视觉内容

2. 模块内容预览区
   - 影视
   - 书
   - 游戏
   - 音乐

3. 每个模块区包含：
   - 模块标题
   - Tab 切换
   - `查看更多`
   - 1 到 2 行作品预览卡片

首页中的作品卡片原则：

- 尽量与对应模块列表页卡片保持一致
- 承担预览和分发作用
- 点击作品进入详情页
- 点击 `查看更多` 进入模块列表页

## 4. 影视模块模板

影视模块适用于：

- 电影
- 电视剧
- 动漫
- 纪录片
- 短片

### 4.1 当前列表页目标

影视列表页应优先支持：

- 快速浏览影视作品
- 在模块内做搜索与筛选
- 从统一列表中进入具体详情页

### 4.2 当前列表页展示字段方向

字段根据卡片布局不同可以有所取舍，但当前优先围绕以下信息组织：

- 海报
- 标题
- 原名
- 年份
- 类型
- 地区
- 导演
- 综合评分
- 简短摘要或一句话信息

说明：

- V1 不额外展示馆长评分与馆长评论字段
- 四方原始评分可作为补充信息，在合适布局下显示

### 4.3 当前列表页筛选项

- 搜索
- 子模块
- 类型
- 地区
- 年份
- 标签

说明：

- 当前暂不开放用户可切换排序
- 默认按上映时间排序

### 4.4 当前详情页信息结构

电影详情页当前采用“左主内容 + 右侧栏”的结构。

左侧主内容：

1. 基础信息区
   - 标题
   - 原名
   - 海报
   - 年份
   - 地区
   - 类型
   - 导演 / 编剧 / 主演
   - 时长
   - 综合评分

2. Tab 分区内容
   - 详情介绍
   - 演职员
   - 精彩影评
   - 视频
   - 图片（剧照 / 海报）
   - 音乐
   - 外部来源

右侧栏：

1. 系列作品
2. 相似作品

说明：

- 系列作品不存在时可隐藏整个模块
- 系列作品和相似作品都支持跳转到对应详情页
- 评论区保留在详情页中展示
- 顶部与列表卡片使用 `synopsis` 短简介
- `详情介绍` Tab 使用 `story` 完整剧情

### 4.5 子模块差异

#### 电影

- 重点突出海报、综合评分、演职员、图片、影评与关联作品

#### 电视剧

- 需要增加季数、集数、平台、状态等字段

#### 动漫

- 可增加原作、制作公司、季度信息等字段

#### 纪录片

- 可强化主题、拍摄地区、叙事视角等字段

#### 短片

- 可强调时长、获奖与观看入口等字段

## 5. 书模块模板

当前仅保留边界定义，后续单独细化。

书模块适用于：

- 网络小说
- 经典文学
- 名著
- 散文随笔
- 漫画

当前原则：

- 列表页结构与影视模块职责相同，但展示字段不完全相同
- 详情页仍采用“基础信息 + 分区内容 + 关联推荐”的思路
- 后续再决定是否采用与影视类似的 Tab 结构

## 6. 音乐模块模板

当前仅保留边界定义，后续单独细化。

音乐模块适用于：

- 专辑
- 单曲
- 原声带
- 演唱会现场
- 音乐人专题

当前原则：

- 列表页与详情页独立设计
- 可延续统一主题气质，但不强制复用影视模块版式

## 7. 游戏模块模板

当前仅保留边界定义，后续单独细化。

游戏模块适用于：

- 单机游戏
- 独立游戏
- 网游
- 手游
- 主机游戏

当前原则：

- 列表页与详情页独立设计
- 后续根据游戏字段特征单独设计信息结构

## 8. 模块模板结论

### 8.1 当前可统一的部分

- 顶部导航
- 主题切换
- 首页“模块预览 + 进入列表页”的分发逻辑
- 列表页的基础职责：搜索、筛选、分页、进入详情页
- 详情页的总体方向：基础信息 + 分区内容 + 关联推荐

### 8.2 当前必须模块独立的部分

- 列表卡片信息组织
- 详情页核心区块
- 具体筛选项
- 关联推荐逻辑
- 图文比例与页面节奏

### 8.3 当前优先级

当前优先推进顺序为：

1. 影视模块
2. 首页与影视列表页 / 详情页之间的闭环
3. 其它模块后续补充
