# 个人收藏馆设计文档 04：UI 风格方向

## 1. 目标

本项目的 UI 目标不是做成传统影视资源站，也不是做成博客，而是做成一个有资料馆气质、又具备现代浏览体验的静态收藏站点。

当前希望同时满足：

- 有明确的个人收藏属性
- 强调资料展示，而不是文章阅读
- 封面、海报、剧照有足够表现力
- 能兼容四大模块长期扩展
- 首页与列表页都具有较强辨识度

## 2. 当前确定的视觉方向

当前已经不再是“单主题候选讨论”，而是明确采用：

**深色资料馆 + 浅色资料馆双主题并存**

说明：

- V1 正式支持用户切换深色 / 浅色主题
- 两套主题都应作为完整体验成立
- 不是简单的界面反色

## 3. 深色主题方向

深色主题承担的角色：

- 建立站点的第一视觉气质
- 放大海报与封面的表现力
- 让首页首屏与影视内容更有沉浸感

关键词：

- 深色背景
- 低亮度层级
- 海报驱动
- 安静
- 资料馆
- 电影感

当前倾向：

- 主背景不使用纯黑，而是石墨黑 / 深灰黑
- 容器层级通过明度差建立，而不是重边框
- 强调海报、剧照、评分等内容焦点

## 4. 浅色主题方向

浅色主题承担的角色：

- 提供更清楚的目录浏览体验
- 提高阅读与筛选时的信息效率
- 让书、音乐、游戏等模块后续更容易扩展

关键词：

- 浅灰白底
- 目录感
- 信息秩序
- 资料系统感
- 清爽

当前倾向：

- 保持足够留白与信息分区
- 通过浅灰层次区分容器，不走后台表单风
- 保留封面表现力，但不过度依赖深色氛围

## 5. 当前参考基准

当前最接近最新共识的视觉参考，不是旧的概念文档描述，而是：

- `design-drafts/movie-list-card.html`
- `design-drafts/movie-list-card-b-comparison.html`

这些设计稿代表了当前更接近有效方向的几个判断：

- 深浅主题都要成立
- 列表卡片允许采用不同布局形式
- 评分、海报、基础信息与扩展信息可以分层展示
- 列表页需要兼顾快速浏览与信息丰富度

## 6. 首页风格方向

首页当前采用“强首屏 + 模块内容预览”的组合模式。

首页视觉目标：

- 首屏具有明显冲击力
- 往下滚动后，模块区有清晰的信息节奏
- 模块区卡片与列表页卡片保持风格连续性

首页不是：

- 纯导航页
- 强馆长长文策展页
- 博客式首页

## 7. 列表页风格方向

列表页要同时满足两点：

- 有明确的资料检索感
- 不失去封面驱动的视觉魅力

当前列表页方向：

- 顶部是搜索与筛选结构
- 中间是作品卡片区
- 卡片支持不同布局探索
- 深色和浅色主题下都要保持良好可读性

## 8. 详情页风格方向

详情页当前方向更接近“资料型电影页”，而不是文章页。

当前目标：

- 上方基础信息清晰
- 下方通过 Tab 管理复杂内容
- 右侧栏承接系列作品与相似作品
- 评论区放在详情页下部

详情页不应：

- 依赖长段正文驱动页面
- 让结构化信息淹没在大段文字中
- 做成博客文章详情页

## 9. 视觉基础建议

### 9.1 字体气质

- 中文以现代无衬线为主
- 英文标题可适度引入更有辨识度的对比字体，但要控制数量
- 列表页与详情页优先保证清晰可读

### 9.2 色彩节奏

- 深色主题：黑灰为主，局部可有克制的强调色
- 浅色主题：白灰为主，强调色用于评分、激活态、链接与操作
- 不使用过度流行化的高饱和彩虹配色

### 9.3 组件气质

- 少用夸张圆角
- 少用厚重阴影
- 鼠标悬停强调信息层次变化，而不是喧宾夺主的动效
- 卡片风格避免“通用组件库感”过强

## 10. 当前应避免的方向

- 博客文章页气质
- 商业影视资源站气质
- 过度后台化的信息系统气质
- 只适合电影、无法承接其它模块的单一风格
- 深浅主题只做表面换色、不做层次重构

## 11. 当前推荐结论

当前最适合继续推进的方向是：

- 首页首屏走更强的视觉冲击路线
- 模块区保持理性与资料化秩序
- 列表页在资料感和封面表现之间找平衡
- 详情页走结构化资料页路线
- 深色 / 浅色主题都作为正式体验设计
