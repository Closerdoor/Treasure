### 2.4 重点推荐参考

#### Letterboxd（最推荐）

与本项目气质最接近，强烈建议深入研究：

- **个人收藏感**：用户标记"看过/想看/喜欢"，评分系统简洁
- **杂志式排版**：海报网格 + 短评卡片，节奏舒适
- **极简详情页**：不堆砌信息，克制展示
- **列表功能**：用户可创建片单，类似策展
- **年度总结**：个人观影统计，有仪式感

#### 豆瓣电影

中文电影站标杆，适合参考：

- **中文信息布局**：适合中文用户习惯
- **评分系统**：五星分布图直观
- **标签系统**：类型标签 + 用户标签
- **评论区**：短评 + 影评分层

#### TMDB

数据来源同时也是设计参考：

- **卡片网格**：现代、响应式
- **海报展示**：高质量、多尺寸
- **搜索体验**：实时搜索、联想
