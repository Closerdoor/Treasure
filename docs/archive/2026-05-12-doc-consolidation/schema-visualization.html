Work（作品主表）

承载所有模块（影视/动漫/书籍/音乐/游戏）的作品基础信息

基础字段
id
String
必填
作品ID。格式：MMSSNNNNNN（MM:模块, SS:子模块, NNNNNN:序号）。示例：0101000001
module
Module
必填
一级模块。枚举：video/anime/book/music/game
submodule
Submodule
可选
二级模块。枚举：movie/tv_series/documentary/short_drama/anime_movie/anime_series
schemaType
SchemaType
必填
Schema类型，决定字段验证规则和前台展示模板
title
String
必填
中文标题（必填）
originalTitle
String
可选
原始标题（英文或源语言）
year
Int
可选
上映/出版年份
country
String
可选
首发国家/地区。规则：单值，按最早真实公映地区推断
language
String
可选
语言（主要对白语言）
publishCompany
String
可选
出品公司/出版社/制作公司
runtimeMinutes
Int
可选
时长（分钟），电影专用
episodeCount
Int
可选
集数，电视剧/番剧专用
episodeRuntimeMinutes
Int
可选
单集时长（分钟），电视剧/番剧专用
synopsisText
String
可选
简介短文
synopsisNote
String
可选
简介备注（如来源说明）
storyText
String
可选
剧情长文。规则：仅已上映作品使用
status
WorkStatus
必填
状态。枚举：draft/published/archived。默认：draft
createdAt
DateTime
必填
创建时间。默认：now()
updatedAt
DateTime
必填
更新时间。自动更新
JSON 字段（一对多数据）
aliasesJson
String
可选
更多片名。示例：["星际启示录", "星际效应"]
releaseDatesJson
String
可选
上映日期。示例：[{ date: "2014-11-05", location: "美国" }]
identifiersJson
String
可选
外部标识符。示例：{ doubanId: "1889243", imdbId: "tt0816692" }
ratingsJson
String
可选
评分信息。统一10分制，不保留votes
linksJson
String
可选
外部来源链接。豆瓣/IMDb/TMDB等
imagesJson
String
可选
图片资源。poster/posters/stills/wallpapers
videosJson
String
可选
视频资源。预告片等
reviewsJson
String
可选
影评。author/source/date/content/url/title
soundtrackJson
String
可选
音乐原声。多专辑结构
relationsJson
String
可选
系列作品/相似作品
quotesJson
String
可选
名言名句。text/speaker/note
episodeStoriesJson
String
可选
分集剧情。电视剧/番剧专用
charactersJson
String
可选
角色介绍。动漫模块专用

Person（公共人物主表）

人物公共资源，支持共享头像、人物跳转链接、跨作品复用

基础字段
id
Int
必填
自增主键
personCode
String
必填
人物代码。格式：p000001。用于生成头像路径等
name
String
必填
中文名
nameEn
String
可选
英文名/原名
avatarPath
String
可选
共享头像路径。相对于 site/public/assets/people/
profileLink
String
可选
默认外链。如 Wikipedia、百度百科等
notes
String
可选
备注
extraJson
String
可选
扩展信息（JSON）

WorkCredit（作品与人物关系表）

承载导演/编剧/主演/制片人/作者/译者/原著/配音等关系

基础字段
id
Int
必填
自增主键
workId
String
必填
作品 ID（外键 → Work）
personId
Int
必填
人物 ID（外键 → Person）
department
Department
必填
部门。枚举：direction/writing/cast/production/music/book/translation/original_work/other
creditType
String
必填
职位类型。如：导演、编剧、主演、制片人
displayLabel
String
可选
显示标签。如角色名："库珀 Cooper"
characterName
String
可选
角色名。演员专用
sortOrder
Int
必填
排序顺序。默认：0
isPrimary
Boolean
必填
是否主要人员。用于前台优先展示。默认：false
linkOverride
String
可选
链接覆盖。如需为该人物在该作品中指定特殊外链
extraJson
String
可选
扩展信息（JSON）

Term（公共词项定义表）

承载 genre（类型）和 tag（标签）

基础字段
id
Int
必填
自增主键
termType
TermType
必填
词项类型。枚举：genre/tag
name
String
必填
名称。如：剧情、犯罪、科幻、经典
moduleScope
String
可选
模块作用域。genre 可按模块建立作用域
submoduleScope
String
可选
子模块作用域
description
String
可选
描述
sortOrder
Int
必填
排序顺序。默认：0
isActive
Boolean
必填
是否启用。默认：true
