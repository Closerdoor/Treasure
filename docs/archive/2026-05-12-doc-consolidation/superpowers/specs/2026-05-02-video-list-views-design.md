# `/video` 列表页双视图设计

## 背景

当前 `/video` 列表页存在两个问题：

1. `列表 / 网格` 切换没有形成明确、可靠的双视图体验。
2. 现有卡片与列表样式没有对齐参考稿 `design-drafts/movie-list-card.html` 的信息结构与视觉层次。

本轮只处理 `/video` 列表页，不改首页卡片语言。

## 已确认约束

- 本轮只改 `/video` 列表页。
- 用户侧文案使用 `卡片 / 列表`，不再使用 `网格`。
- 默认视图为 `卡片`。
- `卡片` 视图需要尽量贴近 `movie-list-card.html` 的悬停表现：普通态信息 + 悬停后海报铺满与底部浮层。
- 继续保留当前筛选逻辑与 URL 参数传递方式，避免扩大范围。

## 目标

让 `/video` 成为一个真正可切换的双视图目录页：

- `卡片` 视图偏视觉浏览与策展感。
- `列表` 视图偏资料浏览与信息密度。
- 两种视图共享同一批筛选结果，但信息排布明显不同。

## 方案选择

本轮采用“最小正确实现”方案。

### 不采用的方案

1. 同时重命名底层 URL 参数为 `view=card|list`
原因：会扩大修改范围，本轮核心问题是视图没有真正落地，而不是参数命名。

2. 顺手重做筛选区与整页布局
原因：这会把范围扩展到目录页整体重设计，不适合当前任务。

### 采用的方案

- 用户看到的切换文案为 `卡片 / 列表`。
- 内部仍沿用现有 `view=grid|list` 参数值，减少改动风险。
- 默认进入 `卡片` 视图，也就是未传 `view` 时按 `grid` 处理。
- 只修改 `/video` 页面、两个影片卡片组件及相关样式、测试。

## 页面行为

### 视图切换

- `/video` 默认显示 `卡片` 视图。
- 点击 `卡片` 时，URL 写入或保持 `view=grid`。
- 点击 `列表` 时，URL 写入 `view=list`。
- 切换视图时必须完整保留已有筛选参数：`q`、`submodule`、`genre`、`country`、`year`、`tag`。

### 工具条文案

- 切换按钮文案从 `列表 / 网格` 改为 `列表 / 卡片`。
- 激活态必须明显可见。
- 页面中的其他说明文案不必同步放大修改，避免本轮范围失控。

## 卡片视图设计

### 布局

- 使用多列响应式海报卡布局。
- 大屏优先呈现高密度卡片墙；中小屏自动减列。
- 每张卡片以海报为主，信息收在卡片底部。

### 普通态内容

- 海报主图。
- 右上角综合评分。
- 海报下方标题。
- 一行基础信息：年份、地区。
- 时长以小角标或贴边信息显示。

### 悬停态内容

- 卡片放大，形成明显但不过度突兀的前景层。
- 普通态海报和底部静态信息淡出。
- 背景海报铺满卡面。
- 卡片底部出现深色渐变浮层。
- 浮层内容包括：
  - 中文标题
  - 年份 / 地区 / 时长
  - 主演预览
  - 2 到 3 行简介摘要

### 风格要求

- 贴近 `movie-list-card.html` 的暗色、海报驱动、悬停揭示信息的逻辑。
- 维持当前站点的资料馆语气，不引入过度娱乐化装饰。
- 允许视觉上更强的 hover，但不改变整体主题系统。

## 列表视图设计

### 布局

- 单列纵向排列。
- 左侧固定海报列，右侧为信息列。
- 整体接近参考稿中的 `card-list` 结构。

### 内容结构

- 标题 + 原名
- 一行基础元信息：年份、地区、类型、导演
- 一段简介摘要
- 一行补充信息：主演预览、时长
- 平台评分 badge：豆瓣 / IMDb / TMDB
- 综合评分块保留，并与主信息区形成清晰层次

### 风格要求

- 比卡片视图更克制、更像目录条目。
- 海报列与信息列比例稳定，不做过度实验性排版。
- 内容密度高于卡片视图，但仍保持清晰呼吸感。

## 组件范围

本轮涉及文件：

## 测试策略

采用 TDD。

### 先写失败测试

- 验证 `/video` 默认视图是 `卡片`。
- 验证视图切换链接文案包含 `卡片` 与 `列表`。
- 验证切换链接保留已有筛选参数。

### 再写最小实现

- 修改页面默认视图逻辑。
- 调整切换链接文案。
- 修改两个卡片组件结构以匹配目标展示。
- 更新样式实现双视图差异。

### 完成后验证

- `npm test`
- `npm run build`

## 非目标

本轮明确不做：

- 首页卡片样式统一
- 筛选区重设计
- 详情页联动调整
- URL 参数从 `grid` 改名为 `card`
- 搜索功能实现

## 完成标准

满足以下条件即可视为本轮完成：

1. `/video` 默认进入 `卡片` 视图。
2. `卡片 / 列表` 切换真实生效。
3. 两种视图呈现结构明显不同，而不是同一内容换容器。
4. `卡片` 与 `列表` 的结构和层次都能看出参考 `movie-list-card.html`。
5. 切换时保留筛选参数。
6. 测试与构建通过。
