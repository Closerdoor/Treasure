# 个人收藏馆设计文档 05：首页与影视模块线框草案

## 1. 目标

本线框文档用于定义首页与影视模块样板页的内容层级、区块关系和交互重点。

## 2. 设计原则

### 2.1 网站气质

- 私人收藏馆 + 档案馆
- 强调内容本身，不展示数量
- 精选型，不是全量资料库

### 2.2 主题风格

- 支持黑白主题切换
- 黑色主题：炫酷、沉浸
- 白色主题：简洁、清爽

### 2.3 网站结构

```
首页 → 模块列表页 → 详情页
```

- 首页：展示最新添加内容 + 各模块精选
- 模块列表页：展示该模块全部内容，支持筛选、分页、搜索
- 详情页：展示单条内容的完整信息

---

## 3. 首页线框（已确认）

### 3.1 页面目标

首页是：

- 个人收藏馆的总入口
- 展示最新添加的内容（跨模块）
- 各模块内容的精选展示区

### 3.2 页面结构

```text
导航栏
最新添加区域（跨模块，最多2行）
影视模块区域
  - Tab: [电影] [电视剧] [动漫] [纪录片] [更多→]
  - 内容卡片（按录入顺序）
书籍模块区域
  - Tab: [名著] [网络小说] [漫画] [更多→]
  - 内容卡片（按录入顺序）
音乐模块区域
  - Tab: [专辑] [单曲] [原声带] [更多→]
  - 内容卡片（按录入顺序）
游戏模块区域
  - Tab: [单机] [独立] [主机] [更多→]
  - 内容卡片（按录入顺序）
页脚
```

### 3.3 区块详细说明

#### 导航栏

内容：

- 站点名
- 一级模块入口（影视/书/音乐/游戏）
- 标签入口
- 搜索入口
- 关于页入口
- 主题切换按钮（黑白主题）

交互要求：

- 桌面端横向排布
- 移动端折叠菜单
- 搜索入口始终保持可达

#### 最新添加区域

目标：

- 第一眼吸引用户
- 展示最近录入的内容

展示规则：

- 跨模块展示（电影+书籍+音乐+游戏混合）
- 最多展示 2 行，可调整为 1 行或 2 行
- 按录入时间倒序排列
- 不展示数量，只展示内容

交互要求：

- 暂不考虑轮播效果
- 卡片 hover 有动效吸引（放大/阴影/渐变等）

#### 各模块区域

每个模块区域结构一致：

1. 模块标题
2. 子模块 Tab 切换
3. 内容卡片展示

Tab 交互规则：

- Tab 用于切换子模块（hover 切换内容）
- 点击 Tab 跳转到对应列表页，并自动添加筛选条件
- 点击"更多"跳转到列表页，无筛选条件

内容展示规则：

- 按录入顺序展示
- 不展示数量
- 每个模块展示若干条内容（具体数量后续确定）

#### 页脚

内容：

- 版权说明
- 数据来源说明
- 评论系统说明（Giscus）

---

## 4. 首页交互流程

### 4.1 从首页到列表页

用户在首页的模块区域：

1. 点击子模块 Tab（如"电影"）→ 跳转影视列表页，筛选条件自动添加"电影"
2. 点击"更多"→ 跳转影视列表页，无筛选条件

### 4.2 Tab 切换行为

- Hover：切换展示内容（不跳转）
- Click：跳转到列表页（带筛选条件）

## 5. 影视模块列表页（已确认）

### 5.1 页面目标

影视列表页承担：

- 展示影视模块下的全部内容
- 支持筛选、分页、搜索
- 子模块切换（电影/电视剧/动漫/纪录片/短片）

### 5.2 页面结构

```text
导航栏
页面标题区（可选）
  - 标题：影视
  - 搜索框
筛选区
  - 子模块 Tab: [电影] [电视剧] [动漫] [纪录片] [短片]
  - 常用筛选: 年份 / 国家 / 类型 / 标签 / 排序
  - 高级筛选（可展开）
内容列表
  - 卡片网格（纵向卡片）
  - 分页
页脚
```

### 5.3 筛选区设计

采用**顶部筛选条**方案：

```text
┌─────────────────────────────────────────────────────────┐
│  影视                                       [搜索框]    │
├─────────────────────────────────────────────────────────┤
│  [电影] [电视剧] [动漫] [纪录片] [短片]    ← 子模块Tab  │
│  ─────────────────────────────────────────────────────  │
│  年份: [全部 ▼]  国家: [全部 ▼]  类型: [全部 ▼]         │
│  标签: [全部 ▼]  排序: [最近录入 ▼]                     │
│                              [高级筛选 ▼]               │
├─────────────────────────────────────────────────────────┤
│  内容卡片网格...                                        │
└─────────────────────────────────────────────────────────┘
```

筛选区特点：

- 子模块 Tab 放在最上方
- 常用筛选放在一行
- "高级筛选"点击后展开更多选项
- 移动端收起为筛选按钮 + 抽屉

### 5.4 列表卡片

采用**海报 + 信息的纵向卡片**：

- 海报/封面
- 标题
- 年份
- 类型/分类
- 馆长评分（可选）
- 其他信息（后续详细讨论）

### 5.5 分页

- V1 先做传统分页（上一页/下一页 + 页码）
- 后续可评估"加载更多"或无限滚动

## 6. 电影详情页线框

### 6.1 页面目标

电影详情页应同时兼顾：

- 作品资料完整展示
- 少量馆长信息展示
- 图片与关联信息展示

### 6.2 页面结构

```text
头图区
基础信息区
简介区
补充备注区
剧照 / 延伸信息区
关联推荐区
评论区
```

### 6.3 区块说明

#### 头图区

内容：

- 海报
- 标题 / 原名
- 年份
- 国家 / 地区
- 导演
- 馆长评分
- 标签

布局建议：

- 桌面端左右分栏
- 左侧海报，右侧主信息
- 移动端改为上下堆叠

#### 基础信息区

内容：

- 导演
- 编剧
- 主演
- 类型
- 时长
- 上映日期
- 外部站点链接

说明：

- 这是详情页最重要的资料块之一
- 应做成清晰的结构化信息区，而不是散文式描述

#### 简介区

内容：

- 官方简介
- 社区整理简介

#### 补充备注区

内容：

- 馆长评分
- 一句简短备注
- 少量补充说明

说明：

- 这里不默认要求大段长评
- 如果某些作品未来有较长评论，也可以在这里扩展

#### 剧照 / 延伸信息区

内容：

- 剧照
- 获奖情况
- 配乐信息
- 相关资料链接

#### 关联推荐区

内容：

- 同导演作品
- 同标签作品
- 同系列作品

#### 评论区

内容：

- Giscus 评论嵌入区

---

## 7. 移动端适配原则

### 7.1 首页

- 最新添加区域改为横向滑动卡片
- 各模块区域改为单列或双列
- Tab 切换保持可用

### 7.2 列表页

- 筛选器收纳为抽屉
- 列表卡片竖向堆叠
- 保留最关键字段，次要字段折叠

### 7.3 详情页

- 海报置顶
- 基础信息分组折叠或分段展示
- 剧照横向滚动
