# 个人收藏馆设计文档 05：首页与影视模块结构定义

## 1. 文档目标

本文件用于统一当前有效的首页、影视模块列表页与电影详情页结构。

说明：

- 本文档覆盖旧版线框中的冲突内容
- 后续实现应优先以本文档为准
- 当前先聚焦影视模块，不展开书 / 游戏 / 音乐的细节设计

## 2. 页面关系

当前站点关系固定为：

```text
首页 -> 模块列表页 -> 详情页
```

在当前阶段，优先实现：

- 首页
- 影视模块列表页
- 电影详情页

## 3. 首页结构

### 3.1 首页定位

首页是总入口与内容发现之间的混合页面。

它需要同时完成：

- 建立站点气质
- 引导进入四大模块
- 预览模块内容
- 把用户分发到模块列表页和详情页

### 3.2 首页结构草图

```text
顶部导航
首屏内容区
影视模块预览区
书模块预览区
游戏模块预览区
音乐模块预览区
页脚
```

### 3.3 顶部导航

内容：

- 站点名
- 四大模块入口
- 搜索入口
- 关于页入口
- 主题切换

说明：

- 主题切换为正式功能
- 搜索入口需要始终可达

### 3.4 首屏内容区

首屏采用混合型表达：

- 有明显的视觉冲击力
- 同时有明确标题和站点说明
- 可以包含精选视觉内容、背景海报、少量重点作品或按钮入口

目标：

- 第一屏就让用户理解站点气质
- 不把首页做成普通目录页

### 3.5 模块预览区

首页向下滚动后，依次展示：

1. 影视
2. 书
3. 游戏
4. 音乐

每个模块区结构一致：

```text
模块标题
Tab 切换：全部 / 子模块 1 / 子模块 2 / ... / 查看更多
1 到 2 行作品卡片预览
```

说明：

- 首页模块区以内容预览为主，而不是单纯模块入口卡片
- 作品预览卡片样式尽量和对应模块列表页卡片保持一致

### 3.6 首页交互规则

- 点击作品卡片 -> 进入对应详情页
- 点击 `查看更多` -> 进入对应模块列表页
- 点击某个子模块入口进入模块列表页时，可自动激活对应筛选条件
- 模块区中的 Tab 可用于切换当前预览内容

## 4. 影视模块列表页

### 4.1 页面目标

影视模块列表页负责展示影视模块下全部内容，并承担影视模块的统一检索入口。

### 4.2 默认状态

当前默认规则：

- 进入影视模块列表页时，默认展示影视模块下全部内容
- 不默认只展示电影
- 如果从首页某个子模块入口进入，并携带了筛选条件，则自动激活对应筛选项

### 4.3 页面结构

```text
顶部导航
页面标题区
搜索与筛选区
影视内容卡片区
分页区
页脚
```

### 4.4 搜索与筛选区

V1 当前需要支持以下筛选功能：

- 搜索
- 子模块：电影 / 电视剧 / 纪录片 / 动漫 / ...
- 类型：全部 / 喜剧 / 动作 / 科幻 / ...
- 地区：美国 / 日本 / 韩国 / 中国大陆 / ...
- 年份
- 标签

说明：

- 排序当前不作为用户可切换功能开放
- 当前固定按上映时间排序

### 4.5 内容卡片区

列表页作品卡片当前可以继续探索不同布局，但需满足以下原则：

- 海报是重要视觉元素
- 标题、年份、类型、地区、导演、综合评分应清晰可见
- 在信息更丰富的布局中，可补充原名、摘要、分平台评分等信息
- 卡片点击后进入详情页

### 4.6 分页

V1 使用传统分页。

说明：

- 先不做无限滚动
- 先不做“加载更多”式交互

## 5. 电影详情页

### 5.1 页面目标

电影详情页直接基于 `data.json` 展示结构化资料。

页面核心目标：

- 基础信息一眼清楚
- 扩展内容分类展示
- 关联作品易于继续浏览

### 5.2 页面结构

电影详情页采用左右结构：

```text
顶部导航
主内容区
  左侧：电影主体内容
  右侧：系列作品 / 相似作品
评论区
页脚
```

### 5.3 左侧主体内容

上方先展示基础信息区，内容包括：

- 海报
- 标题 / 原名
- 年份
- 地区
- 类型
- 导演 / 编剧 / 主演
- 时长
- 综合评分

下方通过 Tab 展示扩展内容。

### 5.4 Tab 结构

当前确认的 Tab 分类如下：

1. 详情介绍
2. 演职员
3. 精彩影评
4. 视频
5. 图片（剧照 / 海报）
6. 音乐
7. 外部来源

说明：

- Tab 内容来源于 `data.json`
- 不直接渲染审阅用 Markdown 页面

### 5.5 右侧栏

右侧栏用于放置关联内容，不放广告。

结构如下：

1. 系列作品
2. 相似作品

规则：

- 系列作品存在时显示
- 若该作品没有系列关系，则隐藏整个系列作品模块
- 相似作品始终作为重要关联区展示
- 两个模块都支持点击进入对应详情页

### 5.6 评论区

详情页保留 Giscus 评论区。

说明：

- 评论区只在详情页中显示
- 列表页和首页不展示评论模块

## 6. 评分展示规则

V1 当前展示的主评分，为以下四个来源评分的综合平均值：

- 豆瓣
- IMDb
- TMDB
- 烂番茄

展示规则：

- 页面必须展示综合平均分
- 在适合的页面位置，可补充展示四个平台原始评分
- 当前不展示馆长评分作为前台主评分

## 7. 主题规则

V1 当前正式支持：

- 深色主题
- 浅色主题

要求：

- 两套主题都应独立成立
- 首页、列表页、详情页都要考虑两套主题下的视觉表现

## 8. 当前已废弃或需要忽略的旧理解

以下内容不再作为当前有效规范：

- 把首页定义成强馆长策展长文页
- 把前台定义成 Markdown / Frontmatter 博客式站点
- 把馆长评分作为 V1 前台主评分
- 把模块列表页默认只看作某一个子模块列表页
