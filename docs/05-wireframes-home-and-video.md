# 个人收藏馆设计文档 05：首页与影视模块线框草案

## 1. 目标

本线框文档用于定义首页与影视模块样板页的内容层级、区块关系和交互重点。

当前默认基于以下视觉方向设计：

- 深色资料馆气质
- 极简资料馆结构

本阶段只做文字线框，不进入像素级视觉稿。

## 2. 首页线框

### 2.1 页面目标

首页不是简单导航页，而是：

- 个人收藏馆的总入口
- 策展展示页
- 最近新增内容的聚合页

### 2.2 页面结构

```text
顶部导航
首屏主视觉
馆长精选
模块入口
最近新增
标签探索
专题推荐 / 馆藏说明
页脚
```

### 2.3 区块说明

#### 顶部导航

内容：

- 站点名
- 一级模块入口
- 标签入口
- 搜索入口
- 关于页入口

交互要求：

- 桌面端横向排布
- 移动端折叠菜单
- 搜索入口始终保持可达

#### 首屏主视觉

目标：

- 在第一屏传达“私人收藏馆”而不是“资源站”

建议元素：

- 站点标题
- 一句简短说明
- 1 个主推荐作品大卡
- 2 到 4 个辅助精选卡片

布局建议：

- 左侧为站点说明
- 右侧为精选封面矩阵或主视觉卡片

#### 馆长精选

目标：

- 展示最值得优先浏览的内容

建议元素：

- 精选条目封面
- 标题
- 模块归属
- 馆长评分
- 一句简短备注

说明：

- 这里的“馆长精选”是筛选结果，不要求大段馆长长评

#### 模块入口

目标：

- 帮助用户迅速进入影视、书、音乐、游戏

建议布局：

- 四个模块卡片
- 每个卡片包含：
- 模块名
- 模块简介
- 条目数量
- 最新录入时间

#### 最近新增

目标：

- 体现网站持续更新

建议元素：

- 封面缩略图
- 标题
- 模块 / 子模块
- 录入日期
- 馆长评分

布局建议：

- 桌面端 2 列或 3 列混合列表
- 移动端单列滚动

#### 标签探索

目标：

- 引导访客通过主题维度发现内容

建议元素：

- 高频标签
- 编辑标签
- 模块标签入口

#### 专题推荐 / 馆藏说明

目标：

- 补充这个站点为什么存在、如何筛选作品、如何理解标签与评分

建议元素：

- 一段站点说明
- 一到两个专题推荐入口

## 3. 影视模块首页线框

### 3.1 页面目标

影视模块首页承担：

- 影视类内容总入口
- 子模块分流
- 影视精选展示

### 3.2 页面结构

```text
模块头图
子模块导航
影视精选
最近新增
按标签探索
按年份 / 地区浏览入口
```

### 3.3 区块说明

#### 模块头图

内容：

- 模块名：影视
- 模块说明
- 总条目数

#### 子模块导航

内容：

- 电影
- 电视剧
- 动漫
- 纪录片
- 短片

设计建议：

- 以标签页或大按钮形式展示
- 要能明显看出当前活跃子模块

#### 影视精选

内容：

- 重点影视条目
- 强调海报、年份、导演、评分

#### 最近新增

内容：

- 最新录入影视内容

#### 标签探索

内容：

- 科幻
- 悬疑
- 成长
- 纪录
- 动画等

#### 按年份 / 地区浏览

内容：

- 年份入口
- 国家 / 地区入口

## 4. 电影列表页线框

### 4.1 页面目标

电影列表页优先解决两件事：

- 快速筛选
- 高效浏览

### 4.2 页面结构

```text
页面头部
筛选栏
排序栏
列表主体
分页 / 加载更多
```

### 4.3 区块说明

#### 页面头部

内容：

- 页面标题：电影
- 简短说明
- 当前结果数

#### 筛选栏

当前先按以下维度设计位置，具体筛选规则后续再细化：

- 年份
- 国家 / 地区
- 类型
- 标签
- 是否馆长精选

交互建议：

- 桌面端显示为横向筛选条 + 抽屉式高级筛选
- 移动端收纳为顶部筛选面板

#### 排序栏

建议预留：

- 最近录入
- 发布时间
- 馆长评分

#### 列表主体

推荐使用纵向卡片列表，而不是纯海报瀑布流。

每个条目建议展示：

- 海报
- 标题 / 原名
- 上映时间
- 国家 / 地区
- 导演
- 类型
- 馆长评分
- 一句简短备注
- 标签

这样做的原因：

- 更适合资料型浏览
- 比纯海报流更适合后续书、音乐、游戏统一设计语言

#### 分页 / 加载更多

建议：

- V1 可先做分页
- 后续再评估是否改为无限加载

## 5. 电影详情页线框

### 5.1 页面目标

电影详情页应同时兼顾：

- 作品资料完整展示
- 少量馆长信息展示
- 图片与关联信息展示

### 5.2 页面结构

```text
头图区
基础信息区
简介区
补充备注区
剧照 / 延伸信息区
关联推荐区
评论区
```

### 5.3 区块说明

#### 头图区

内容：

- 海报
- 标题 / 原名
- 年份
- 国家 / 地区
- 导演
- 馆长评分
- 标签

布局建议：

- 桌面端左右分栏
- 左侧海报，右侧主信息
- 移动端改为上下堆叠

#### 基础信息区

内容：

- 导演
- 编剧
- 主演
- 类型
- 时长
- 上映日期
- 外部站点链接

说明：

- 这是详情页最重要的资料块之一
- 应做成清晰的结构化信息区，而不是散文式描述

#### 简介区

内容：

- 官方简介
- 社区整理简介

#### 补充备注区

内容：

- 馆长评分
- 一句简短备注
- 少量补充说明

说明：

- 这里不默认要求大段长评
- 如果某些作品未来有较长评论，也可以在这里扩展

#### 剧照 / 延伸信息区

内容：

- 剧照
- 获奖情况
- 配乐信息
- 相关资料链接

#### 关联推荐区

内容：

- 同导演作品
- 同标签作品
- 同系列作品

#### 评论区

内容：

- Giscus 评论嵌入区

## 6. 移动端原则

### 6.1 首页

- 首屏主视觉缩减层级
- 精选区改为横向滑动卡片
- 最近新增改为单列

### 6.2 列表页

- 筛选器收纳为抽屉
- 列表卡片竖向堆叠
- 保留最关键字段，次要字段折叠

### 6.3 详情页

- 海报置顶
- 基础信息分组折叠或分段展示
- 剧照横向滚动

## 7. 当前结论

这一轮线框草案明确了：首页和影视模块不应走“个人博客式长文”路线，而应采用：

- 首页偏策展入口
- 列表页偏资料浏览
- 详情页偏结构化信息展示
- 馆长内容为少量筛选、标签、评分和补充说明

下一阶段建议继续设计：

- 电影模块详细字段 schema
- 首页和电影页面的高保真视觉方向
- 书 / 音乐 / 游戏模块的页面骨架差异
