# 个人收藏馆设计文档 02：模块模板草案

## 1. 模板设计原则

本项目不采用"全站一套内容模板"的方式，而采用以下三层结构：

1. 全站统一骨架
   - 导航
   - 页头页脚
   - 视觉系统
   - 标签系统
   - 搜索体验

2. 模块级模板独立
   - 影视模板
   - 图书模板
   - 音乐模板
   - 游戏模板

3. 子模块按模块模板派生
   - 子模块继承对应模块的主骨架
   - 根据内容特征调整字段、筛选项和详情区块

目标是同时满足：

- 模块差异足够大
- 视觉与交互保持统一
- 后续新增条目可按模板快速扩展

## 2. 全站统一骨架

所有页面共享以下结构：

1. 顶部导航
   - Logo / 站点名
   - 一级模块入口
   - 标签入口
   - 搜索入口
   - 关于页入口

2. 页面头图区
   - 当前页面标题
   - 页面简介
   - 面包屑导航

3. 主内容区
   - 筛选区或正文区
   - 内容卡片列表或详情内容

4. 页面侧边信息区
   - 标签聚合
   - 最近新增
   - 相关内容推荐

5. 页脚
   - 版权说明
   - 评论入口说明
   - 数据来源说明

## 3. 首页模板草案

首页定位：

- 策展型首页
- 最近新增作为次重点内容区

建议区块：

1. 站点主视觉区
   - 站点标题
   - 一句策展说明
   - 精选模块入口

2. 馆长精选区
   - 重点展示近期最值得推荐的内容

3. 模块入口区
   - 影视
   - 书
   - 音乐
   - 游戏

4. 最近新增区
   - 按录入时间排序展示最新内容

5. 标签探索区
   - 展示高频内容标签与馆藏标签

6. 馆长策展区
   - 长文或专题入口

## 4. 影视模块模板

影视模块适用于：

- 电影
- 电视剧
- 动漫
- 纪录片
- 短片

### 4.1 列表页目标

列表页应优先支持：

- 快速浏览作品基础信息
- 使用标签和条件筛选
- 通过馆长短评判断是否值得点进详情页

### 4.2 列表页建议字段

- 海报
- 标题
- 原名
- 上映日期
- 国家 / 地区
- 导演
- 类型
- 馆长评分
- 一句话短评
- 标签

### 4.3 列表页筛选项

待后续详细设计时再细化，当前先预留以下方向：

- 子模块
- 年份
- 国家 / 地区
- 类型
- 标签
- 馆长精选
- 排序方式

### 4.4 详情页信息区块

1. 基础信息区
   - 标题
   - 原名
   - 海报
   - 上映日期
   - 国家 / 地区
   - 导演 / 编剧 / 主演
   - 类型
   - 时长或集数

2. 简介区
   - 官方简介
   - 馆长导读

3. 馆长评论区
   - 馆长评分
   - 一句话短评
   - 长评
   - 推荐理由

4. 延伸信息区
   - 剧照
   - 配乐或 OST
   - 获奖情况
   - 外部资料链接

5. 关联内容区
   - 同导演作品
   - 同标签作品
   - 同系列作品

6. 评论区
   - Giscus 评论

### 4.5 子模块差异

#### 电影

- 重点突出海报、导演、上映年份、时长、长评

#### 电视剧

- 增加集数、季数、连载状态、平台等字段

#### 动漫

- 可增加原作、制作公司、季度信息等字段

#### 纪录片

- 可强化主题类型、拍摄地区、叙事视角等字段

#### 短片

- 可强调时长、获奖、观看入口等字段

## 6. 音乐模块模板

音乐模块适用于：

- 专辑
- 单曲
- 原声带
- 演唱会现场
- 音乐人专题

### 6.1 列表页建议字段

- 封面
- 专辑名 / 曲名
- 艺术家
- 发行时间
- 风格
- 馆长评分
- 一句话短评
- 标签

### 6.2 详情页信息区块

1. 基础信息区
   - 标题
   - 艺术家
   - 发行时间
   - 厂牌
   - 风格
   - 封面

2. 简介区
   - 作品简介
   - 背景说明

3. 听感评论区
   - 馆长评分
   - 短评
   - 长评
   - 推荐曲

4. 曲目区
   - 曲目列表
   - 重点曲目说明

5. 延伸信息区
   - 现场图
   - MV 或演出信息
   - 外部资料链接

6. 关联内容区
   - 同艺术家
   - 同风格
   - 同标签推荐

### 6.3 子模块差异

#### 专辑

- 强调完整曲目、整体叙事、封面与时代背景

#### 单曲

- 强调单曲本身的亮点与场景感

#### 原声带

- 增加关联影视 / 游戏作品字段

#### 演唱会现场

- 增加场地、时间、歌单、现场表现等字段

#### 音乐人专题

- 更接近专题页而非单一作品详情页

### 7.2 详情页信息区块

1. 基础信息区
   - 游戏名
   - 平台
   - 发售日期
   - 开发商
   - 发行商
   - 类型
   - 封面

2. 游戏简介区

- 增加运营周期、社交性、版本更新等字段

#### 手游

- 增加平台信息、商业模式、碎片化体验等字段

## 8. 模块模板对比结论

### 8.1 可以全站统一的部分

- 顶部导航
- 标签交互方式
- 搜索入口
- 页面基础布局系统
- 卡片设计规范
- 评论接入方式

### 8.2 必须模块独立的部分

- 列表字段
- 详情页核心区块
- 筛选条件
- 推荐逻辑
- 图文比例

### 8.3 后续设计重点

接下来需要继续设计的内容包括：

- 影视模块的详细线框
- 首页的内容层级与视觉方向
- 各模块的字段 schema
- 批量录入模板与内容文件格式
- 图片目录与命名规范
