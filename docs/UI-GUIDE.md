# UI Guide

> Purpose: 记录当前生效的前台界面设计方向、页面结构与交互规则。
> Status: active
> Scope: 视觉方向、主题、首页、列表页、详情页、卡片与交互
> Out of scope: workflow 细节、阶段进度、完整 schema 表
> Update triggers: 页面结构变化、交互变化、主题变化、设计基准变化
> Priority: 4

## 整体视觉方向

当前前台不是传统影视资源站，也不是博客，而是“资料馆气质 + 现代浏览体验”的静态收藏站点。

核心要求：

- 强调结构化资料展示
- 海报、封面、剧照有足够表现力
- 不走博客文章页气质
- 不走后台信息系统气质

## 主题策略

当前正式采用：

- 深色资料馆主题
- 浅色资料馆主题

说明：

- 两套主题都必须独立成立
- 不是简单反色
- 深色更强调沉浸感与海报表现力
- 浅色更强调目录感与信息效率

## 首页

### 定位

首页是总入口与内容预览之间的混合页面，不是纯导航页，也不是策展长文页。

### 当前结构

- 顶部导航
- 首屏 Hero 区
- 影视模块预览区
- 书模块预览区
- 游戏模块预览区
- 音乐模块预览区
- 页脚

### Hero 区必须包含

- 站点标题
- 简介 / 副标题
- 主题切换入口
- 全站搜索入口 UI
- 精选海报或背景视觉
- 主入口按钮
- 少量精选作品直达入口

### 模块预览区规则

- 每个模块区包含：标题、Tab、`查看更多`、1 到 2 行作品预览
- 首页模块区固定使用网格卡片
- 首页作品卡片应与列表页网格卡片保持风格连续
- 不额外单独设计首页专用卡片体系

当前 V1 阶段补充说明：

- 影视模块优先承载真实内容预览与跳转链路
- 书 / 音乐 / 游戏模块可以先作为弱化入口或占位预览存在
- 未完成对应模块列表页与详情页前，不强制要求这些模块具备完整跳转链路
- 首页当前已经完成第一轮样板落地
- 首页后续优化依赖更高内容密度，当前不继续深抠视觉细节

交互规则：

- `Hover` Tab：切换当前预览
- 已落地真实链路的模块中，`Click` Tab：跳转到对应模块列表页
- 已落地真实链路的模块中，点击 `查看更多`：跳转到对应模块列表页
- 已落地真实链路的模块中，点击作品卡片：进入对应详情页
- 未落地真实链路的模块中，`Tab`、`查看更多` 与作品卡片默认不点击，只作为视觉占位或弱化入口存在

## 搜索

当前搜索范围已确认如下：

- 首页顶部搜索属于全站搜索入口 UI
- 模块列表页内搜索属于当前模块内搜索入口 UI
- 搜索结果未来应落到独立搜索结果页
- 当前阶段先保留搜索入口 UI，不实现搜索能力

## 影视列表页

### 默认状态

- 默认展示影视模块下全部内容
- 如果从首页带筛选条件进入，则自动激活对应筛选

### 页面结构

- 顶部导航
- 页面标题区
- 搜索与筛选区
- 内容卡片区
- 分页区
- 页脚

### V1 筛选项

- 搜索
- 子模块
- 类型
- 地区
- 年份

### 排序

- V1 不开放用户手动排序切换
- 默认按上映时间排序

### 卡片模式

当前已确认影视模块列表页支持两种布局切换：

1. 卡片模式
- 海报在上，信息在下
- 更适合首页模块预览和快速扫视

2. 列表模式
- 海报在左，信息在右
- 更适合影视模块主列表与高信息密度浏览

补充规则：

- 用户侧文案统一使用 `卡片 / 列表`
- 默认视图为 `卡片`
- 底层 URL 参数仍保留 `view=grid|list`
- 首页预览更适合网格模式或其变体
- 影视列表主视图更适合列表模式或其变体
- 两种布局都应支持深色 / 浅色主题
- 布局切换不改变筛选结果本身

#### 首页网格卡片

默认展示：

- 海报
- 标题
- 年份
- 类型
- 地区
- 综合评分
- 时长

悬停补充：

- 简介

补充规则：

- 主演信息如果进入网格卡片，只展示一行，溢出直接隐藏

#### 列表页列表卡片

默认展示：

- 海报
- 标题
- 原名
- 年份
- 地区
- 类型
- 导演
- 综合评分
- 简介
- 前 3 位主演
- 四个平台原始评分

补充规则：

- 标签不进入卡片展示，只用于搜索与筛选
- 四个平台原始评分只显示分数，不显示评价人数或补充说明
- 只显示当前有值的平台，不给缺失平台做占位

## 电影详情页

### 总体结构

采用左右结构：

- 左侧为电影主体内容
- 右侧为关联内容
- 左侧标题索引 sticky，并与站点头部贴边
- 右侧栏保持 sticky

### 顶部基础信息区

当前目标是参考豆瓣电影的信息组织方式，但 UI 不照搬，且更偏本站资料馆风格。

顶部优先展示：

- 海报
- 中文标题
- 原名
- `年份 | 类型`
- 导演
- 编剧
- 主演
- 地区
- 语言
- 片长
- 上映日期
- 更多片名
- 简介
- 综合评分单值

补充规则：

- 顶部不会展示全量资料
- 顶部只展示最重要的一部分字段
- 顶部主演只展示前几位主角信息
- 顶部主演以文字方式展示，不在头部做完整人物卡
- 顶部简介读取 `synopsis`
- `详情介绍` Tab 读取 `story`
- 评分只显示单个总分值，不展示额外说明文案
- 标题字号当前固定，不做响应式缩放
- 海报桌面端固定宽度为 `310px`

### Tab 结构

当前确认包括：

1. 详情介绍
2. 演职员
3. 图片
4. 精彩影评
5. 音乐
6. 视频
7. 外部来源

数据规则：

- `详情介绍` 读取 `story`
- 顶部摘要与列表卡片读取 `synopsis`
- `精彩影评` 使用精选长评或高质量评语
- `演职员` Tab 承载完整人物展示，包含图片、姓名、职位 / 饰演角色
- `视频` Tab 只展示视频封面、标题、来源，并跳转外部页面
- `图片` Tab 使用双行横向展示，第一行优先海报 / 剧照，第二行展示其它图片，两行联动滚动
- `外部来源` Tab 使用简洁链接列表，只展示站点名与跳转链接

交互规则：

- 标题索引滚动时自动高亮当前 section
- 索引区最右侧提供 `回到顶部` 快捷按钮
- 演职员内容为单行横向滚动，使用左右按钮控制
- 视频内容为单行横向滚动，使用左右按钮控制
- 图片内容为双行联动横向滚动，使用一组居中左右按钮控制
- 不依赖底部原生滚动条作为主要交互

### 右侧栏

- 系列作品
- 相似作品

规则：

- 无系列作品时隐藏该模块
- 已录入站内、且详情页已存在的作品支持跳转到对应详情页
- 未录入站内的作品允许先以占位卡展示
- 占位卡不可点击，不跳外链
- 占位状态使用精简展示：标题 / 年份 / 海报（如有）/ 综合评分（如有）/ `暂未收录` 标记
- `series` 当前按上映时间排序

补充规则：

- 列表页与详情页当前的信息结构已基本稳定
- 后续允许继续做视觉与排版微调，但不轻易改动字段骨架与主交互组织

### 评论区

- Giscus 只保留在详情页

## About 页

About 页属于 V1 范围内页面，但定位保持克制。

当前最低要求：

- 说明站点定位是“精选型个人收藏馆”
- 说明这是馆长筛选型收藏站，而不是全量资料库
- 简要说明当前内容来源与整理原则
- 风格保持资料馆气质，不写成长篇博客自述

## 评分展示

当前前台评分规则：

- 主评分为豆瓣 / IMDb / TMDB / 烂番茄四方综合平均值
- 所有平台分数统一按 10 分制理解与展示
- 烂番茄在参与综合评分时先从百分比换算成 10 分制
- 缺失的平台直接跳过，只对有值平台求平均
- 综合评分最终展示保留 1 位小数
- 可补充展示各平台原始评分
- 不展示馆长评分作为主评分

## 当前避免的方向

- 博客文章页风格
- 纯工具型后台风格
- 单一只适合电影、无法延展到其它模块的视觉体系
- 用短评或馆长主观文案替代结构化资料展示
