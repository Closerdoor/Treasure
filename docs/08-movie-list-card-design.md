# 电影列表页卡片设计

## 1. 设计概述

列表页支持**两种布局切换**，用户可通过按钮切换：

- **布局 A**：海报在上，信息在下（网格模式）
- **布局 B**：海报在左，信息在右（列表模式）

---

## 2. 布局 A：网格模式

### 2.1 卡片结构

```
┌─────────────────┐
│                 │
│     海报        │
│    (竖版)       │
│                 │
├─────────────────┤
│ 肖申克的救赎    │  ← 标题
│ 1994 · 剧情     │  ← 年份 · 类型
│ ★ 9.5           │  ← 评分
└─────────────────┘
```

### 2.2 卡片尺寸

- 海报比例：2:3（标准电影海报比例）
- 卡片宽度：180px - 220px（响应式）
- 海报高度：270px - 330px
- 信息区高度：80px - 100px

### 2.3 网格排列

| 屏幕宽度 | 列数 | 卡片宽度 |
|----------|------|----------|
| 1440px+ | 6 列 | 200px |
| 1200px | 5 列 | 200px |
| 1024px | 4 列 | 200px |
| 768px | 3 列 | 200px |
| 480px | 2 列 | 180px |

## 4. 卡片信息字段对比

| 字段 | 布局 A（网格） | 布局 B（列表） |
|------|---------------|---------------|
| 海报 | ✓ 大图 | ✓ 小图 |
| 标题 | ✓ | ✓ |
| 原名 | ✗ | ✓ |
| 年份 | ✓ | ✓ |
| 国家 | ✗ | ✓ |
| 类型 | ✓ | ✓ |
| 导演 | ✗ | ✓ |
| 评分 | ✓ | ✓ |
| 短评 | ✗ | ✓ |

**说明**：
- 布局 A 信息精简，适合快速浏览
- 布局 B 信息丰富，适合详细筛选

## 5. 卡片交互设计

### 5.1 Hover 效果

#### 布局 A（网格模式）

- 海报：轻微放大（scale: 1.05）
- 卡片：阴影加深
- 信息区：背景色变化
- 整体：cursor: pointer

#### 布局 B（列表模式）

- 海报：轻微放大
- 信息区：背景色变化
- 标题：颜色变化（主题色）
- 整体：cursor: pointer

### 5.2 点击行为

- 点击整个卡片 → 跳转详情页
- 右键 → 新标签页打开（浏览器默认行为）

### 5.3 布局切换按钮

位置：筛选区右侧

```
[网格图标] [列表图标]  ← 点击切换
```

- 当前选中的图标高亮
- 切换时保持筛选条件
- 切换时保持滚动位置（可选）
- 记住用户选择（localStorage）
