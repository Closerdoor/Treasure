# 电影列表卡片设计说明

## 1. 文档定位

本文档用于记录当前电影列表卡片设计的有效结论，以及可继续探索的方向。

说明：

- 当前卡片设计仍处于演进中
- 以 `design-drafts/movie-list-card.html` 和 `movie-list-card-b-comparison.html` 为主要参考
- 若与旧文档中的馆长评分或旧字段设定冲突，以当前文档为准

## 2. 当前设计目标

电影列表卡片需要同时满足：

- 能快速识别作品
- 能承载基础资料信息
- 在深色 / 浅色主题下都成立
- 与首页模块预览卡片保持风格连续性
- 支持从“快速浏览”到“信息更丰富”两种阅读方式

## 3. 当前允许的两种布局方向

### 3.1 布局 A：网格模式

特点：

- 海报在上，信息在下
- 更适合快速扫视与封面浏览
- 更适合首页模块区和高密度列表区

建议展示字段：

- 海报
- 标题
- 年份
- 类型
- 地区
- 综合评分

悬停时可补充展示：

- 主演
- 一句摘要
- 更多元数据

### 3.2 布局 B：列表模式

特点：

- 海报在左，信息在右
- 更适合信息密度更高的浏览方式
- 更适合影视模块列表页主列表

建议展示字段：

- 海报
- 标题
- 原名
- 年份
- 地区
- 类型
- 导演
- 综合评分
- 简短摘要

可选补充字段：

- 主演
- 各平台原始评分
- 标签

## 4. 当前评分规则

当前卡片评分展示需要遵守：

- 主评分显示为四个平台评分的综合平均值
- 四个平台分别为：豆瓣、IMDb、TMDB、烂番茄
- 分平台原始评分可作为补充信息展示
- 当前不展示馆长评分作为卡片主评分

## 5. 当前字段优先级

### 必要字段

- 海报
- 标题
- 年份
- 类型
- 综合评分

### 高优先级字段

- 原名
- 地区
- 导演
- 简短摘要

### 可选字段

- 主演
- 标签
- 分平台评分
- 时长

## 6. 当前交互原则

- 点击整个卡片进入详情页
- 悬停态可以强化信息层次，但不应影响布局稳定性
- 深色 / 浅色主题下都要保持良好的可读性
- 首页模块区卡片应尽量与列表页卡片风格一致

## 7. 当前不建议的方向

- 只展示封面，不展示足够资料信息
- 把卡片做成博客文章摘要卡
- 把馆长短评当作默认主要文案
- 依赖过多复杂动效才能成立

## 8. 当前结论

当前最适合继续推进的方向是：

- 首页模块预览更适合优先采用网格模式或基于网格模式的变体
- 影视模块列表页更适合优先采用信息更完整的列表模式或其变体
- 两种模式不一定都在 V1 正式开放给用户切换，但都可以作为设计探索基线
