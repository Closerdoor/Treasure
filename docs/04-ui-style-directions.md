# 个人收藏馆设计文档 04：UI 风格方向

## 1. 目标

本项目的 UI 不应做成常见的影视资源站或信息聚合站，而应体现以下气质：

- 有明确的个人收藏属性
- 强调精选与归档感
- 能承载多模块内容，而不只适用于影视
- 适合静态站点长期维护
- 视觉上有辨识度，但不过度装饰

由于项目的内容核心是“馆长筛选 + 社区资料整合”，而不是大量个人长评，因此视觉应以“资料馆 + 策展感”为主，而不是博客感。

## 2. 风格方案 A：深色资料馆

### 2.1 关键词

- 深色背景
- 强对比封面
- 安静
- 电影感
- 档案馆

### 2.2 适合原因

- 很适合影视模块起步
- 海报、封面、剧照在深色背景上表现力强
- 能把“收藏馆”做得更像私人影像资料室
- 对 Giscus 和内容卡片也比较友好

### 2.3 首页气质

- 首屏像一张策展海报墙
- 精选内容的封面冲击力强
- 最近新增区有明显的资料归档感

### 2.4 列表页气质

- 封面主导
- 文字信息克制排列
- 筛选器更像资料库控制台

### 2.5 详情页气质

- 海报和主图更突出
- 信息卡与正文区形成层次
- 剧照、标签和资料块更容易组织

### 2.6 风险

- 如果书籍、散文、古典音乐较多，深色风格可能显得略重
- 需要控制页面压迫感，避免像商业影视站

## 3. 风格方案 B：极简资料馆

### 3.1 关键词

- 浅底
- 网格秩序
- 冷静
- 目录感
- 检索感

### 3.2 适合原因

- 对书、音乐、游戏的兼容性最好
- 更像一个真正的个人归档系统
- 结构清晰，适合多筛选、多标签、多模块并行发展

### 3.3 首页气质

- 像策展目录页
- 模块入口、精选内容、最新内容分区清楚
- 更偏资料平台而不是情绪化展示

### 3.4 列表页气质

- 信息效率高
- 卡片和列表都能成立
- 适合后续扩展复杂筛选

### 3.5 详情页气质

- 信息区块非常清楚
- 适合大段元数据展示
- 不容易被单一模块风格绑死

### 3.6 风险

- 如果处理不好，可能会显得过于“后台化”或偏冷
- 首页第一眼冲击力不如深色方案

## 4. 风格方案 C：文艺馆藏风

### 4.1 关键词

- 温暖纸感
- 留白
- 书卷气
- 收藏票据感
- 手工编目感

### 4.2 适合原因

- 很符合“收藏馆”这个命名
- 对书籍和音乐尤其友好
- 能让站点有很强的个人辨识度

### 4.3 首页气质

- 更像一个线上展册首页
- 可以用策展语句和精选条目建立氛围

### 4.4 列表页气质

- 卡片可能更像索引卡
- 适合突出标题、标签、录入时间和备注

### 4.5 详情页气质

- 适合展示摘录、资料、封面和少量备注
- 适合“个人档案”而不是“商业资源页”

### 4.6 风险

- 如果影视内容占比很高，可能不够锐利
- 过于文艺化会削弱检索与资料感

## 5. 风格方案 D：杂志策展风

### 5.1 关键词

- 大字号标题
- 编排感
- 专题感
- 块面切分
- 首页冲击力强

### 5.2 适合原因

- 非常适合首页和专题页
- 能突出“精选”和“策展推荐”
- 适合做首页与模块首页的视觉记忆点

### 5.3 首页气质

- 首页像一本数字杂志封面
- 精选内容、模块分区、标签都能做出鲜明版式

### 5.4 列表页气质

- 可做得更有节奏感
- 但需要控制，不然复杂筛选会被牺牲

### 5.5 详情页气质

- 适合重点作品做大图大标题
- 普通条目可能会显得略重

### 5.6 风险

- 开发和维护复杂度较高
- 容易让多模块之间风格不统一

## 6. 四种方案对比

### 6.1 最适合当前项目的两种

如果以你的需求为准，我认为最值得优先考虑的是：

1. 深色资料馆
2. 极简资料馆

原因：

- 都适合长期扩展
- 都能兼顾“精选”和“资料”
- 都比较适合静态站点持续维护

### 6.2 我更推荐的方向

我建议最终采用：

**深色资料馆为主，吸收极简资料馆的结构秩序。**

也就是：

- 视觉气质偏深色、沉浸、封面导向
- 版式结构偏极简、理性、检索友好

这样更适合：

- 首页有足够辨识度
- 影视模块表现力强
- 书、音乐、游戏也不会难以承接

## 7. 建议的视觉基础设定

如果采用推荐方向，建议基础设定如下：

### 7.1 背景

- 主背景：深灰黑，不使用纯黑
- 内容卡背景：稍亮一层的石墨色
- 局部点缀：低饱和暖灰或暗金

### 7.2 字体气质

- 中文：偏现代但有质感的无衬线
- 英文标题：可搭配轻微展示型衬线或高对比无衬线

### 7.3 卡片风格

- 封面卡片边框弱化
- 信息层次清晰
- 避免过度圆角和流行组件感

### 7.4 页面节奏

- 首页强调策展段落感
- 列表页强调筛选效率
- 详情页强调资料块与图片的层次感

## 8. 推荐结论

当前建议你优先考虑以下顺序：

1. 深色资料馆 + 极简结构
2. 极简资料馆
3. 文艺馆藏风
4. 杂志策展风

下一步应基于推荐方向，先绘制：

- 首页线框
- 影视模块首页线框
- 电影列表页线框
- 电影详情页线框
