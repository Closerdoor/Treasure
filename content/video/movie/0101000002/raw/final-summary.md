## 最终组合策略

### 主数据源：豆瓣

**获取字段（20个）：**
- title, originalTitle, year, genre, country, language, runtime, releaseDate, aka
- imdbId, doubanId, doubanRating, doubanVotes
- director, writer, cast, otherCast, producer
- synopsis, reviews, similar
- images（海报、剧照、壁纸）, videos

**优势：**
- 中文数据最完整
- 演职员信息详细
- 图片资源丰富
- 有预告片链接
- 有相似推荐

### 补充数据源1：百度百科

**补充字段（10个）：**
- soundtrack（13首曲目）✅ 独有
- boxOffice（票房数据）✅ 独有
- filmingDates（拍摄日期）✅ 独有
- productionCompany（发行公司）✅ 独有
- tomatoMeter, tomatoUserMeter, metascore, cinemaScore ✅ 独有
- rated（MPAA评级）
- 详细剧情介绍
- 更多演员角色说明

### 补充数据源2：OMDb

**补充字段（4个）：**
- rated（MPAA评级）✅ 独有
- awards（获奖信息）✅ 独有
- runtimeEn（IMDb片长127分钟）
- synopsisEn（英文剧情简介）

### 补充数据源3：Wikipedia

**补充字段（2个）：**
- wikibaseId（Wikidata ID）✅ 独有
- 演职员头像（8个）✅ 独有

### 不可用数据源

| 数据源 | 原因 | 替代方案 |
|--------|------|----------|
| TMDB | 电影未收录 | 暂无替代，等待收录 |
| IMDb | 直接访问被禁止 | 通过OMDb间接获取 |

## 推荐工作流程

```
1. 豆瓣获取主数据（20个字段）
   └─ 需登录 + 图片防盗链处理

2. 百度百科补充（10个字段）
   └─ 无需登录，直接WebFetch

3. OMDb补充（4个字段）
   └─ API调用，需API Key

4. Wikipedia补充（2个字段）
   └─ API调用，无需认证
   └─ 单独查询每个演员获取头像

5. 数据合并与冲突处理
   └─ 按优先级选择主值
   └─ 记录差异和冲突

6. 图片下载
   └─ 豆瓣图片：带Referer下载
   └─ Wikipedia图片：直接下载
```

## 结论

通过**豆瓣为主 + 百度百科 + OMDb + Wikipedia**的组合策略，可以获取**89%**的字段数据，满足电影录入的基本需求。

**各数据源定位：**
- **豆瓣**：主数据源，中文数据最完整
- **百度百科**：补充原声带、票房、评分
- **OMDb**：补充评级、获奖
- **Wikipedia**：补充头像、Wikidata ID
- **TMDB**：暂不可用，待收录后补充
- **IMDb**：通过OMDb间接获取，直接访问受限
